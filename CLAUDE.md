## Project goal

- This repo started as `expo/expo-livekit-template`. It is becoming "German AI Teacher": a voice-first AI German teacher for Spanish and English speakers who live in Germany. It will later be sold as a subscription app on iOS and Android.
- It is built in public, so all code, comments, docs and commit messages are in English.
- The current agent in `agent/agent.ts` is "Valentina", a Spanish restaurant reservation agent. A German teacher called "Lena" will replace her. Valentina is preserved on the git branch `mirador-guane`.
- Target learners are at levels A1 to B1. Lessons focus on real-life situations in Germany.
